# MAGNO LTDA

Site institucional de Magno Andrade. HTML, CSS e JavaScript estáticos; arquivos públicos em `dist/`.

Publicação na Vercel: framework Other, diretório de saída `dist`, sem instalação ou build.

O formulário prepara uma mensagem no navegador; o visitante confirma o envio no WhatsApp. Não há banco de dados ou login.
